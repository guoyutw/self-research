# Review protocol

Self Research has two review layers. Neither layer silently changes the public method or personal model.

## Research-cycle review

At the end of each bounded cycle, record: what the current cases taught; which hypothesis strengthened or weakened; which counterexample or competing explanation mattered; what remains unresolved; what, if anything, changes in the current model; and the next bounded test.

## Method review

Ask which questions produced evidence, which led or distorted, whether theory displaced owner language, what was overinterpreted, and what should be kept, revised, reverted, or retired. Review does not automatically add a rule; avoid sediment.

## Shared-method evolution

```text
candidate method lesson → real validation evidence → owner approval
→ versioned change → CHANGELOG
```

A lesson must be supported by generalized, de-identified evidence. Raw/private evidence remains private. The owner approves shared/public changes; no model or agent may authorize its own permanent rule change. Git history keeps prior versions inspectable and reversible.

## Boundaries

Session-level notes may guide the next private interaction without changing this repository. A public change affects all users and therefore requires the full evidence, approval, versioning, and changelog path.
