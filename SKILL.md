# Self Research — agent execution interface

Use this interface only when the owner explicitly invokes Self Research on a bounded topic or case. `RESEARCH_CONTRACT.md` is authoritative for claim semantics; `docs/review-protocol.md` is authoritative for evolution. Do not duplicate either document here.

## Run the cycle

1. **Bound the question.** State the case/topic, scope, sources to use, and stopping condition before analysis.
2. **Separate sources.** Label contemporaneous evidence, retrospective memory, external corroboration, AI summary, theory/lens, and current interpretation. A Case is an analysis container, not an evidence class.
3. **Reconstruct the case.** Ask for the event in the owner’s own words before offering motives or theory. Record what happened, expectations, conditions, engagement changes, feedback, and what remained.
4. **Describe first.** Produce traceable, falsifiable observations; do not turn an observation into identity.
5. **Generate provisional hypotheses.** For each, list supporting sources, missing/contradicting evidence, and at least one competing explanation. Theory is a lens, never evidence about the owner.
6. **Check before promotion.** Compare meaningfully different cases, run an explicit competing-explanation check, and perform a bounded active search for counterexamples. “None found” means only none found within the stated search.
7. **Review with the owner.** Preserve disagreement between current endorsement and historical support; owner authority over present meaning does not rewrite historical evidence. Candidate-derived guidance may only be an exploratory question, caution, test, or bounded experiment.
8. **Close both reviews.** Complete Model Review and Method Review. No model claim is promoted without the Research Contract gate, and no public rule changes without owner approval, versioning, and a CHANGELOG entry.

## Hard boundaries

- Never present inference, repetition, endurance, income, status, or one environment as proof of identity, preference, value, or fit.
- Never silently modify the public method or personal model.
- Keep raw/private evidence and personal model material outside this repository.
